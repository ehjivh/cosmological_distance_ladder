# 星までの距離はどうやって測る？

天体までの距離を測る手法群の連鎖（**宇宙の距離梯子 / Cosmic Distance Ladder**）を、
来館者や学習者が自ら操作しながら学べる教育用Webアプリです。

解説を読むだけでなく、観測データのパラメーターをスライダーやタップで操作し、
自分の手で距離を導き出す体験を提供します。

---

- **単一HTMLファイルで完結**（外部通信・依存ライブラリなし）

## 学べる4つのステップ

前のステップをクリアしないと次に進めない「較正の連鎖」を体験できます。

| STEP | 手法                 | 対象範囲                           | 操作内容                                          |
| ---- | -------------------- | ---------------------------------- | ------------------------------------------------- |
| 1    | **年周視差**         | 約数百光年以内（地上望遠鏡の場合） | 公転位相スライダーを動かし、視差角 p を測定       |
| 2    | **セファイド変光星** | 約数千万光年以内                   | 変光周期を測り、周期-光度関係から距離を導出       |

| 4    | **赤方偏移**         | 観測可能な宇宙の最果て             | スペクトルのズレ z を測り、ハッブル定数 H₀ を算出 |

## 計算ロジック詳細

各ステップの物理モデルと、コード内での実装を対応させて解説します。
アプリは**教育的なわかりやすさを優先した簡略スケール**を用いており、
天文単位系の厳密な絶対値ではなく「関係性（反比例・対数線形・べき乗など）」を体感させることを目的としています。

### 共通定数

| 定数       | 値     | 意味                       |
| ---------- | ------ | -------------------------- |
| `PC_TO_LY` | 3.2616 | 1パーセク → 光年の換算係数 |
| `C`        | 299792 | 光速 [km/s]                |

補足：環境依存で `Math.log10` が未定義の場合に備え、冒頭でポリフィルを定義しています。

~~~javascript
if(!Math.log10) Math.log10 = x => Math.log(x) / Math.LN10;
~~~

### STEP 1：年周視差（Parallax）

**物理原理**：地球の公転（基線＝軌道直径）により、近い星は遠い背景星に対して見かけ上ずれて見える。
そのずれ角（視差 p）と距離 d は反比例する。

$$
d\,[\mathrm{pc}] = \frac{1}{p\,[\text{arcsec}]}
$$

**実装のポイント**：画面を「宇宙俯瞰ビュー」と「望遠鏡視野ビュー」に分離し、
「宇宙での実際の距離」と「地球から見た見かけの振れ」を混同させないよう表現。

- 距離スライダー `distNorm`（1〜1000）を大きくする → 俯瞰図では対象星が奥へ移動
- 公転位相 `phase` を変える → 望遠鏡視野では見かけ位置が左右に振れる（＝視差）
- 見かけの振れ幅は距離に反比例（遠いほど振れが小さい）

~~~javascript
// 望遠鏡視野内での見かけの振れ（距離に反比例、位相で±に振れる）
const parallaxPix = Math.cos(phase) * (60 * (100 / distNorm));

// 表示用の視差角と距離（d = 1/p の関係を体感させるスケール）
const parallaxArcsec = 1000 / distNorm;      // 距離に反比例
const dpc = 1 / parallaxArcsec * 1000;       // d = 1/p
const dly = dpc * PC_TO_LY;                   // 光年へ換算
~~~

**クリア条件**：軌道の両端（`cos(phase) > 0.85` と `< -0.85`）の両方で観測し、
視差を確認するとSTEP2が解放される。

~~~javascript
if (Math.cos(phase) >  0.85) seenRight = true;
if (Math.cos(phase) < -0.85) seenLeft  = true;
const ok = seenLeft && seenRight;   // 両端観測でクリア
~~~

### STEP 2：セファイド変光星（周期-光度関係）

**物理原理**：セファイド変光星は「変光周期 P が長いほど絶対等級 M が明るい（負に大きい）」。
周期から真の明るさ（絶対等級 M）が分かり、見かけの等級 m と比較して距離を求める（距離指数）。

$$
M = -2.43\,(\log_{10} P - 1) - 4.05
$$
$$
m - M = 5\log_{10} d - 5 \quad\Rightarrow\quad d\,[\mathrm{pc}] = 10^{\frac{m - M + 5}{5}}
$$

**実装**：周期 P（1〜100日）をスライダーで指定。見かけ等級 m は遠方銀河の観測値として固定（14.5）。

~~~javascript
const P = parseInt(period2.value);            // 変光周期 [日]
const M = -2.43 * (Math.log10(P) - 1) - 4.05; // 周期-光度関係
const m = 14.5;                               // 見かけの等級（観測値）
const dpc = Math.pow(10, (m - M + 5) / 5);    // 距離指数の式
const dly = dpc * PC_TO_LY;                    // 光年へ換算
~~~

**光度曲線の描画**：セファイド特有の「急上昇・緩降下」の非対称な変光を再現。

~~~javascript
// cyc: 位相 0..1。前半25%で急上昇、残り75%で緩やかに降下
let b = cyc < 0.25 ? cyc / 0.25 : 1 - (cyc - 0.25) / 0.75;
~~~

### STEP 3：Ia型超新星（標準光源）

**物理原理**：白色矮星が伴星からガスを得てチャンドラセカール限界（約 1.4 太陽質量）に達すると爆発。
ピーク光度がほぼ一定（絶対等級 M ≒ -19.3）なため「標準光源」として距離測定に使える。

$$
d\,[\mathrm{pc}] = 10^{\frac{m - M + 5}{5}}, \quad M \approx -19.3
$$

**実装**：観測されたピーク見かけ等級 m（14〜24）をスライダーで指定し距離を算出。

~~~javascript
const m = parseFloat(mSN.value);              // ピーク見かけ等級
const M = -19.3;                              // 標準光源の絶対等級
const dpc = Math.pow(10, (m - M + 5) / 5);    // 距離指数の式
const dly = dpc * PC_TO_LY;                    // 光年へ換算
~~~

**爆発アニメーション**：`snPhase`（0→1）で進行を管理。

- `snPhase < 0.6`：伴星からの降着流＋チャンドラセカール限界ゲージの充填
- `snPhase >= 0.6`：放射状グラデーションで大爆発を表現

~~~javascript
const growth = Math.min(snPhase / 0.6, 1);    // 限界質量への到達度 0..1
// 質量表示：1.0 → 1.4 M☉ へ near-linear に増加
const mass = (1.0 + 0.4 * growth).toFixed(2);
~~~

### STEP 4：赤方偏移（ハッブルの法則）

**物理原理**：宇宙膨張により遠方銀河の光は波長が伸びる（赤方偏移 z）。
後退速度 v は z に比例し、距離 d とも比例（ハッブルの法則）。

$$
v = c\,z \qquad v = H_0\,d
$$

**実装**：スペクトル線のズレ z をスライダーで指定し、後退速度 v を算出。

~~~javascript
const z = parseFloat(zval.value);   // 赤方偏移
const v = Math.round(C * z);        // 後退速度 v = c·z [km/s]
~~~

**ハッブル定数のフィット**：プロットした複数点 (d, v) に対し、
原点を通る直線 `v = H0·d` を最小二乗法でフィットして H₀ を算出。

$$
H_0 = \frac{\sum d_i v_i}{\sum d_i^{2}}
$$

~~~javascript
// 原点通過の最小二乗フィット（傾き = ハッブル定数 H0）
let sxx = 0, sxy = 0;
hubblePts.forEach(p => { sxx += p.d * p.d; sxy += p.d * p.v; });
const H0 = sxy / sxx;   // v = H0·d の傾き [km/s/Mpc]
~~~

3点以上プロットするとフィットが確定し、距離梯子が「完成」する。

### 状態管理とロック制御

各ステップの完了フラグを `state` オブジェクトで一元管理し、
前ステップ未完了時は次ステップをロック（較正の連鎖を強制）。

~~~javascript
const state = {
  step1Done: false, step2Done: false, step3Done: false,
  d1: null, d2: null, d3: null   // 各ステップで確定した距離
};

function unlocked(i){
  if (i === 0) return true;              // STEP1は常に解放
  if (i === 1) return state.step1Done;   // STEP2はSTEP1完了で解放
  if (i === 2) return state.step2Done;   // STEP3はSTEP2完了で解放
  if (i === 3) return state.step3Done;   // STEP4はSTEP3完了で解放
}
~~~
